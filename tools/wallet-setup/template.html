오프라인 지갑 설정 도구

회원 입금 주소를 만들 시드(복구 단어)와 서버에 넣을 공개키(xpub)를 만듭니다. 이 파일은 인터넷을 전혀 사용하지 않습니다.

⚠ 인터넷에 연결되어 있습니다. Wi-Fi/랜선을 끊은 뒤 사용하세요. (권장: 다 쓴 뒤 브라우저를 닫고 다시 연결)

사용 순서

  1. 인터넷을 끊고 이 파일을 브라우저로 엽니다.
  2. 새 시드 생성을 누르고, 나온 24단어를 종이에 순서대로 적어 안전한 곳에 보관합니다. (사진·캡처·메모앱·클라우드 저장 금지)
  3. 아래 환경변수 3줄을 복사해 Vercel → Settings → Environment Variables 에 추가합니다. (xpub 은 공개키라 서버에 넣어도 코인을 빼갈 수 없습니다)
  4. 모두 지우기를 누르고 브라우저를 닫은 뒤 인터넷을 다시 연결합니다.
  5. 배포 후 관리자 → 코인 입금 화면의 "회사 메인 주소"가 여기 표시된 #0 주소와 같은지 확인합니다.
24단어를 잃어버리면 회원들이 입금한 코인을 영구히 꺼낼 수 없습니다. 반대로 24단어가 유출되면 누구나 모든 입금 주소의 코인을 가져갈 수 있습니다. 한 번 설정한 xpub 은 바꾸지 마세요.
